# ⑦ Mac で試す手順（初心者向け・約15分）

**やること**：Obsidian のノートから「自分の言葉」がうまく取り出せるかを、自分の目で確かめる。

**安心してほしいこと**
- ノートは **読むだけ**。書き換え・削除・移動はしません。
- インターネットにも Google Drive にも **何も送りません**。
- 作られるのは、デスクトップの結果ファイル2つだけです（不要なら、ゴミ箱に捨てれば元どおり）。

---

## ステップ1：道具をダウンロードする（3分）

1. Mac の **Safari** で、次のリンクを開きます（クリックするとダウンロードが始まります）。
   https://github.com/YDI1222/-2026/archive/refs/heads/claude/ai-orchestration-handoff-opnmu8.zip
2. **ダウンロード** フォルダに `-2026-claude-ai-orchestration-handoff-opnmu8` というフォルダができます。
   （zip のままなら、ダブルクリックすると開きます）
3. このフォルダの名前を **`yojo-ai`** に変えて、**書類** フォルダへ移動します。
   - 名前の変え方：フォルダを1回クリック → Enter キー → 入力 → Enter

## ステップ2：Obsidian の保管庫の場所を確認する（2分）

1. Obsidian を開き、左のファイル一覧で **どれか1つのノートを右クリック** →「**Finderで表示**」。
2. Finder が開き、そのノートが選ばれた状態になります。
3. 上にたどって、**「Second Brain」など保管庫の名前のフォルダ** を見つけます。これを後で使います。
   - 間違ったフォルダを選んでも、スクリプトが「保管庫ではないようです」と教えてくれるので大丈夫です。

## ステップ3：ターミナルを開く（1分）

1. キーボードで **⌘（command）＋ スペース** を押す
2. 「**ターミナル**」と入力して Enter
3. 白か黒の文字だけの画面が開きます。これがターミナルです。

## ステップ4：スクリプトを動かす（3分）

1. ターミナルに **`bash `** と入力します（bash のあとに **半角スペース1つ**。まだ Enter は押さない）。
2. Finder で `書類 › yojo-ai › AI_Orchestration › workflows › content_design` を開き、
   **`try_digest_mac.sh`** をターミナルの画面に **ドラッグ＆ドロップ** します。
   → 長い文字（ファイルの場所）が自動で入ります。
3. **Enter** を押します。
4. 「保管庫フォルダをドラッグ＆ドロップして」と出たら、ステップ2の **保管庫フォルダ** をドラッグ＆ドロップして **Enter**。
5. 「できました」と出て、結果が **テキストエディット** で開きます。

### 途中で出るかもしれない画面
| 出てくる画面 | 押すボタン | 理由 |
|---|---|---|
| 「“ターミナル”から“書類”フォルダ内のファイルにアクセスしようとしています」 | **許可** | ノートを読むため（読むだけ） |
| 「コマンドライン・デベロッパ・ツールをインストールしますか？」 | **インストール** → 完了後、ステップ4をもう一度 | Apple 公式の部品。初回だけ（数分〜10分） |

## ステップ5：結果を見る（5分）

結果ファイル（デスクトップの `insight_digest_試し_日付.md`）で、次の3つだけ見てください。

1. 並んでいる文章は **「確かに自分の言葉だ」** と思えるか
2. **発信に使ってほしくない私的な内容** が入っていないか
3. **大事な気づきが漏れていないか**（漏れていたら、そのノートの日付をメモ）

見方：
- `## INS-20261012-1｜問い（健康経営）` … 10月12日のノートの1つ目の気づき。種類は「問い」
- `> …` の部分 … ノートの原文そのまま
- 「要確認」… 個人が特定されそうなので、**本文を出さずに場所だけ** 表示したもの
- 少なすぎる時：ステップ4の1で `bash ` の代わりに入力した行の最後に ` 30` を足すと、30日分で試せます

## ステップ6：Claude に感想を伝える

次の3点を Claude に伝えてください。**ノートの中身を貼る必要はありません。**
- 画面の一番上に出た1行（例：`[warn] 気づき 6 件（ノート 9 件、要確認で除外 1 件…）`）
- 上の確認1〜3の感想（例：「2割くらい日記っぽいものが混ざる」「10/3 の気づきが拾われていない」）
- 拾ってほしくない種類があれば、その特徴（例：「体調の記録」「家族の話」）

→ 判定のルールを調整します。

## うまくいかない時

| 画面の表示 | 原因と対処 |
|---|---|
| `No such file or directory` | ステップ4の2で `try_digest_mac.sh` をドラッグできていません。もう一度 `bash ` から |
| 「そのフォルダが見つかりません」 | フォルダそのものではなく、中のファイルをドラッグした可能性。フォルダをドラッグ |
| 「Obsidian の保管庫ではないようです」 | 1つ上か下のフォルダが保管庫です。ステップ2をもう一度 |
| 「python3 がまだ使えません」 | 「インストール」を押して完了を待ち、ステップ4をもう一度 |
| 「Operation not permitted」 | システム設定 › プライバシーとセキュリティ › フルディスクアクセス で「ターミナル」をオン → ターミナルを再起動 |
| それ以外のエラー | ターミナルの文字を全部コピーして Claude に貼り付け（ノート本文は表示されない作りです） |
